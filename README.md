# BtrKorone (BtrRoblox)

BtrKorone is a lightweight browser enhancement extension and userscript specifically designed for the **Korone** Roblox revival website (formerly known as Pekora). 

Just like RoPro or BTRoblox enhance the official Roblox site, BtrKorone tweaks the Korone frontend to add quality-of-life improvements, better navigation, and missing features to make your 2017–2021 revival experience seamless.

---

## ✨ Features

* **UI Enhancements:** Modernizes and cleans up the Korone website layout.
* **Trading Enhancements:** 
* **Quick Navigation:** Adds useful shortcuts and navigation tweaks that the base site lacks.
* **Customization:** Minor visual tweaks to give you a more personalized revival experience.
* **Optimized Performance:** Lightweight script that doesn't slow down your browsing.

---

## 🚀 Installation

### Method 1: Manual Extension Install (GitHub)
1. Download this repository as a `.zip` file and extract it.
2. Open your browser's extension page (e.g., `chrome://extensions` or `edge://extensions`).
3. Enable **Developer Mode** (usually a toggle in the top right).
4. Click **Load unpacked** and select the extracted project folder.
